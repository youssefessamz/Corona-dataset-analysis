# COVID-19 Business Case: Pandas Workshop

Data cleaning, exploration, and visualization of a COVID-19 patient dataset using pandas.

## Structure
- `data/covid_data_cleaned.csv`: cleaned dataset (~236k rows)
- `notebooks/visual.ipynb`: analysis and visualizations
- `docs/COVID19_Business_Case_Pandas_Workshop_answered.docx`: workshop questions with answers

## Run
```bash
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook notebooks/visual.ipynb
```
